# Balemoh API client

This is the standalone Go module containing the generated OpenAPI client for
Balemoh's public API contract. The generated source is intentionally kept
separate from the API server and is consumed by the sibling `ui` BFF module.

Regenerate after changing [`../api/openapi.yaml`](../api/openapi.yaml):

```sh
GOWORK=off go generate ./...
GOWORK=off go test ./...
```

Do not edit `balemoh.gen.go` by hand; it is generated by `oapi-codegen`.
