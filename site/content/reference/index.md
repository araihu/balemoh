# Reference

- [API integration](api-integration/index.md), with a create-and-pin workflow, authentication boundaries, retries, and response formats.
- [API environment](api-environment/index.md), generated by envdoc from API configuration types.
- [UI environment](ui-environment/index.md), generated by envdoc from UI configuration types.
- [Icon library](icons/index.md), including upload limits, collection provenance, and persistence.
- [OpenAPI documentation](https://balemoh.araihu.com/openapi/catalogs/balemoh/documents/openapi/), exported by Manja from `api/openapi.yaml`.

The build copies generated environment references directly from the repository.
Runtime configuration uses `caarlos0/env/v11`; this site does not maintain a
second list of defaults.
