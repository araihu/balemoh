# Features and guides

Balemoh gives your homelab a homepage of services you choose. Discovery finds
candidates, Staging lets you review them, and homepage search opens the services
you have pinned. Optional host telemetry adds CPU and memory readings beside them.

| What you want to do | Guide |
| --- | --- |
| Open a service without scanning every card | [Search services](search/index.md) |
| Find Kubernetes, Docker, or Podman services and add them to your homepage | [Automatic service discovery](discovery/index.md) |
| Check host CPU, memory, usage history, and workload inventory | [Basic host telemetry](host-telemetry/index.md) |
| Collect services from several machines or clusters | [Federated agents](federation/index.md) |
| Choose or upload a service icon | [Icon library](../reference/icons/index.md) |

Start with [installation](../getting-started/index.md) if you do not have an
instance running yet. The search box on this documentation site searches these
docs. Service search runs inside your own Balemoh instance.
